motor physics
Owns
Its internal control circuit maps pulse width → shaft angle (~1.5 ms ≈ center). The camera rides this platform, so aiming and seeing are one loop.

~500–2500 µs pulse / 20 ms → physical shaft rotation
range 0–180°, per-servo calibrated
