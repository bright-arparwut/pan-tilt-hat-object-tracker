One lap of the loop

Four physical components, one closed circuit. Sight travels up, a command comes down, and the loop closes through the physical world — the camera rides the very platform it aims, so every move changes what the next frame sees.

The lap — six legs, then back to the start

  1. 1
    Video · up · cyan

    Camera → Mac

    USB camera → MJPEG over HTTP (multipart/x-mixed-replace), port 8000 → Mac ingests via CameraSource — no new code. ~50–200 ms.

  2. 2
    Think · Mac

    Detect → track → aim

    YOLO + ByteTrack → Target Selector latches the followed id → error = target_center − frame_center → Aim Controller step() → AimCommand.

  3. 3
    Command · down · amber

    Mac → Pi

    One UDP JSON datagram {pan_delta, tilt_delta, seq} on port 9000 → run_listener → freshest-wins → apply_delta. ~50–200 ms.

  4. 4
    Drive · internal

    Pi → board

    ServoDriver clamps to limits → kit.servo[n].angle → I²C writes to PCA9685 at 0x40.

  5. 5
    Move · internal

    board → servos

    PCA9685 emits 50 Hz PWM → the two servos (pan ch 0 / tilt ch 1) rotate the platform.

  6. 6
    Close the loop · physical

    servos → camera’s field of view

    The camera rides the platform, so the move changes what the next frame sees.

back to leg 1 — a smaller error each lap.
